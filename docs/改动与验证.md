8. Drive 目录统一从配置读取，移除原来隐藏的固定目录 ID。
9. 本地 Worker 不再将飞书 access token 持久化进 `request.json`；仅向飞书/Lark 域名发送飞书下载认证头。
10. 按截图补齐字段模板及按钮配置说明；原图和真实素材没有加入项目。

## 验证方法

```sh
node tests/test_workflows.cjs
python -m unittest discover -s tests -p 'test_worker.py' -v
```

Python 测试需已安装 `worker/requirements.txt` 中的依赖。测试通过模块导入运行，使用临时数据目录和测试密钥，不读取原目录 `.env`，不发起模型请求。

- 工作流：50 个离线场景，覆盖两套流程的成功、重复点击、缺视频、失败/取消/过期、缺失/字符串/秒级/毫秒级服务器时间、多个节点传输失败、飞书业务错误、缺任务/文件 ID、失败回写自身失败。
- Worker：6 个回归测试，包含 API 密钥校验、临时 Token 不落盘、9 秒限制、音频参数透传、明显时长偏差拒绝，以及真实 FFmpeg 音频测试。
- 音频测试用 440 Hz 原音与 880 Hz 模拟模型声音，确认结果保留原音，丢弃模型音轨；另验证无音轨源仍无声。
- 工作流节点引用、连接、代码语法在离线模拟中检查；最终 15 个文件已通过针对原配置和已知密钥的扫描，未发现匹配残留；两套工作流各 40 个节点，均默认未启用、无固定测试数据。
